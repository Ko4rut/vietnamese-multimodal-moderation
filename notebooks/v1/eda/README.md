# Silver EDA — before Gold

This V1 folder contains `01_silver_eda.ipynb`, generated by
`scripts/04_generate_silver_eda_notebook.py`.

## Install dependencies (Windows PowerShell)

Run from the repository root after checking out `feat/silver-pipeline-v1`:

```powershell
git checkout feat/silver-pipeline-v1
git pull origin feat/silver-pipeline-v1

# Create and activate a virtual environment only if you do not already have one.
py -3 -m venv venv
.\venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -e ".[dev,eda]"
python -m pip check
```

If your `(venv)` is already active, **skip** creating and activating another environment.
Use `python -m pip install -e ".[eda]"` if you only need EDA, or `".[dev,eda]"`
to include pytest and Ruff. To use the Hugging Face ingestion script as well,
install `".[dev,data,eda]"`. The `pyproject.toml` file declares dependencies;
`pip install -e ...` actually installs them into the **active Python environment**.

For Jupyter Lab, start from the repository root:

```powershell
python -m jupyter lab notebooks/v1/eda/01_silver_eda.ipynb
```

In VS Code, open the same notebook and choose the Python interpreter/kernel
belonging to your venv. Optional kernel registration if it does not appear:

```powershell
python -m ipykernel install --user --name vmm-eda --display-name "Python (VMM EDA)"
```

## Configure Data Lake

Set `DATA_LAKE_ROOT` to the **existing** local/mounted dataset folder in the
repository root `.env` (or set it as an environment variable):

```dotenv
DATA_LAKE_ROOT=E:/path/to/vietnamese-multilabel-topic-classification
```

This is an **example path**, not a Drive URL. If you launched Jupyter from another
working directory, use `DATA_LAKE_ROOT_OVERRIDE = r"E:\path\to\data-lake"` in
the notebook configuration cell instead of relying on the repo-root `.env`.

Set `SILVER_REPORT_NAME` in notebook Section 0 to the actual JSON filename inside
`04_reports/`. `SilverReader.verify()` checks the Silver snapshot before EDA.

## Outputs and scope

Charts come from real Silver data: domain distribution, character-length histogram,
length-by-domain boxplots, crawl-noise bars, domain/noise heatmap, and Bronze→Silver
comparison. A bounded TF-IDF similarity sample gives **candidates**, not an exhaustive
leakage audit. Label validity must still be reviewed before Gold.

The notebook reads the existing snapshots without transforming them or creating Gold.
By default, `EXPORT_RESULTS=False` and nothing is written. If set to `True`,
it exports summary JSON and PNGs to
`04_reports/eda/<silver_snapshot_stem>/` and refuses to overwrite existing files.
Text snippets appear only in notebook output; exported summary has no raw articles.
