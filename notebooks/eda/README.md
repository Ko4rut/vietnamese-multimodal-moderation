# Silver EDA — before Gold

This folder contains `01_silver_eda.ipynb`, generated by `scripts/04_generate_silver_eda_notebook.py`.

Install from the repository root:

```bash
python -m pip install -e ".[eda]"
```

Set `DATA_LAKE_ROOT` in the environment or repository `.env`, and update `SILVER_REPORT_NAME` in notebook Section 0 to match the actual file under `05_reports/`. Open the notebook from the cloned repository in Jupyter or VS Code. In Colab, clone branch `feat/silver-pipeline-v1`, mount the correct Drive, install extras, and run from the project directory.

Charts are produced from **real Silver data**: 25 topic-label frequencies, character-length histogram, length-by-domain boxplots, crawl-noise bars, domain/noise heatmap, and Bronze→Silver text comparison. A bounded TF-IDF similarity sample provides *candidates*, not a full leakage audit.

The notebook never transforms source snapshots or generates Gold outputs. Set `EXPORT_RESULTS=True` only if you want summary JSON and PNG images written under `05_reports/eda/<silver_snapshot_stem>/`. It refuses to overwrite existing output files. Text snippets only appear in the notebook display; exported summary contains no raw articles.

To regenerate the notebook:

```bash
python scripts/04_generate_silver_eda_notebook.py
python scripts/04_generate_silver_eda_notebook.py --check
```
